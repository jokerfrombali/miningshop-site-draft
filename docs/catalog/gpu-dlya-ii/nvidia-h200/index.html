Для каких задач

NVIDIA H200 — флагман для обучения. Подходит для задач: обучение и дообучение больших языковых моделей, инференс моделей на сотни миллиардов параметров.

Особенности

Главное отличие от H100 — память: 141 ГБ HBM3e против 80 ГБ и почти в полтора раза большая пропускная способность. Для LLM это означает, что крупная модель помещается на меньшее число карт, а инференс идёт быстрее.

Что учесть при покупке

  • Формат. PCIe-карты ставятся в стандартный сервер; SXM-модули — только в платформы с соответствующей платой.
  • Охлаждение. Серверные карты с пассивным радиатором требуют корпуса с направленным продувом.
  • Питание. Считайте блок питания по суммарному TDP всех карт с запасом 20–30 %.
  • Происхождение. Проверьте, не прошла ли карта через майнинг-ферму и есть ли на неё гарантия.

Не уверены, какая карта нужна? Сравните варианты в разделе GPU для ИИ или посмотрите готовые конфигурации серверов.
