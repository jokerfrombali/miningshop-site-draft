# Черновик нового сайта MiningShop (в стиле gekard.ru)

Отложенная работа: статический сайт на 81 страницу, собранный генератором из `src/`.
В живой сайт miningshop.ru ничего из этого не выкладывалось.

- `src/` — генератор и тексты: каталог ASIC (26 моделей, включая возвращённые со старого сайта по
  прежним адресам), GPU для ИИ (10 ускорителей), GPU-серверы, комплектующие, калькулятор доходности `/table/`,
  8 переписанных руководств старого блога по старым адресам `/blog/...`, услуги, страницы компании.
- `docs/` — готовая сборка (все страницы с `noindex`, robots.txt запрещает индексацию).

Сборка: `python src/build.py`. Просмотр: раздать папку `docs` любым HTTP-сервером под путём `/miningshop-site/`.
